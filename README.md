# Enclosure Designer — конструктор щитів

Безкоштовна програма для Windows 10 / 11: компонування модульних електрощитів, апарати на DIN-рейках,
проводи з маркуванням, однолінійна схема, специфікація з цінами, наклейки на пластрон, експорт PDF.

- **[Завантажити останню версію](https://github.com/YevgenZhylenkov/enclosure-designer-releases/releases/latest)** — файл `EnclosureDesigner-Setup-<версія>.exe` у розділі «Assets».
- **[Сайт програми та інструкція](https://yevgenzhylenkov.github.io/enclosure-designer-releases/)**
- **[Історія версій](https://yevgenzhylenkov.github.io/enclosure-designer-releases/changelog/)**

Встановлення не потребує прав адміністратора. Нові версії програма пропонує встановити сама.

У цьому репозиторії лише інсталятори та сайт програми; вихідного коду тут немає.
